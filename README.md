# Pocketful of Rooms

A cosy sticker game for kids: decorate little rooms with animal friends, furniture, plants, treats and more. It runs in the browser.

**Play it on itch.io: <https://gahrae.itch.io/pocketful-of-rooms>**

[![A cosy pink bedroom made in Pocketful of Rooms](cover.png)](https://gahrae.itch.io/pocketful-of-rooms)

This repository only redirects to the game's itch.io page. Found a bug or have an idea? Leave a comment on the itch.io page.
